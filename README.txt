- `index.html` — home
- `about.html` — about the school
- `departments.html` — technical trades
- `tutorials.html` — learning resources
- `entertainment.html` — entertainment

- `advertisements.html` — advertisements
- `admissions.html` — admissions information

- `404.html` — not-found page

## What was improved
- Standardized filenames and internal links to lowercase names for reliable hosting.
- Added a Timetable link to the navigation menus.
- Improved responsive navigation, current-page highlighting, footer year, search filtering, focus visibility, reduced-motion support and image lazy-loading.
- Added favicon and 404 page.
- Kept the existing school page content and existing image/content references.

## Before publishing
1. Upload **all files in this folder** to the same GitHub repository root (or the same website folder).
2. Make sure `index.html` is in the repository root.
3. Replace the school's contact placeholders only with information confirmed by the school.
4. In `script.js`, set `schoolEmail` to the school's verified official email if the school wants the contact form to open the visitor's email application.

## Important limitations
This is a static HTML/CSS/JavaScript website. The contact form does not store or deliver messages to a school server. It will clearly tell visitors that the official email is not configured until a verified address is added. Online admission applications, accounts, databases, administrator news publishing and message storage require a backend or a trusted form service.

The timetable content is labelled as a sample and should not be presented as the official school timetable unless the school verifies it. Stock/illustrative images are not photographs of Mutovu TSS. Replace them with authorized school photographs when available.
